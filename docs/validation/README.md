# Validation records

Per-issue and per-release evidence from stage 2 on, grouped by milestone or topic (index in
[VALIDATION.md](../VALIDATION.md#stage-2-and-later-files)). One section per issue or record;
append new evidence to the file of its group and add an index row only when a new file is
created. Keep acceptance tables, scenario statuses and every "Not run" or pending statement;
condense live-run narrative to counts, status and limits. Never record private addresses, MACs
or host names. Do not recreate per-issue files.
