# Requirement-to-evidence traceability

This matrix links every **Must** requirement in [REQUIREMENTS.md](REQUIREMENTS.md) and
every automated scenario T01–T21 in [VALIDATION.md](VALIDATION.md) to the automated
tests or scripts that exercise it. It is a map of where evidence lives, not a record of
executed results: actual runs are recorded per candidate in the pull request, CI and the
dated sections of VALIDATION.md.

All referenced automated evidence uses mocks, `tmp_path` data and synthetic loopback
processes on `127.0.0.1`; none of it contacts a LAN device. Hardware checks H01–H07
([VALIDATION.md](VALIDATION.md#read-only-hardware-checks)) and deployment/hub evidence
are not covered by any automated reference and stay visibly pending: H01 and H04–H07 belong
to [#12](https://github.com/descipar/wled-mcp/issues/12), H02/H03, deployment, hub
integration and resource measurements to
[#11](https://github.com/descipar/wled-mcp/issues/11); live version-to-version
update/rollback is moved to stage 2 ([#21](https://github.com/descipar/wled-mcp/issues/21), [#25](https://github.com/descipar/wled-mcp/issues/25)) per ISSUE-11-DEC-005. One live check of both #11 modes, a live HTTP
service removal and redeploy, and the follow-up catalog/preset reads, stdio rebuild and
hub container recreation are recorded in
[VALIDATION.md](VALIDATION.md#issue-11-live-deployment-check-2026-11-06); the cells
below name only what remains open.

`scripts/check_traceability.py` (run by `tests/test_traceability.py` in ordinary CI)
rejects a Must requirement without a row, a duplicate row, an unmapped T-scenario, any
hardware/deployment cell other than `pending: ...` or `not applicable: ...`, and
outcome claims (verified, tested, checked, accepted, observed, OK, ...) in those cells,
the scenario status or notes; neutral wording such as "to be done" or "not yet tested"
is allowed. An Evidence cell may only list comma-separated backtick references to an
existing test function `tests/test_*.py::test_<name>`, a test group such as
`test_T05_*` or `test_T05_replace_*` (every test whose name starts with that stem), or a
file directly inside `scripts/` (`.py`) or `.github/workflows/` (`.yml`). A bare test
file, a non-test name, a catch-all `test_*`, a path leaving its directory or free text
is not evidence.
